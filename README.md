# Техническое задание (ТЗ)
## Программа "Генератор комбинаций блюд"

---

## Общее описание
Консольное приложение на Java для управления списком блюд и генерации случайных комбинаций блюд по заданным типам.

### Главное меню
При запуске программа отображает меню:
Выберите действие:
1 — Добавить новое блюдо
2 — Сгенерировать комбинации блюд
3 — Выход

text

---

## 1. Добавление нового блюда

### 1.1. Описание
Программа поочерёдно запрашивает у пользователя **тип** и **название** блюда и сохраняет их.

### 1.2. Порядок работы
| Шаг | Действие пользователя | Реакция программы |
|-----|----------------------|-------------------|
| 1 | Выбор пункта меню `1` | `"Введите тип блюда:"` |
| 2 | Ввод строки (тип) | Сохраняет тип |
| 3 | `"Введите название блюда:"` |
| 4 | Ввод строки (название) | Сохраняет название |
| 5 | `"Блюдо 'X' (тип: Y) успешно добавлено"` |
| 6 | Возврат в главное меню |

### 1.3. Правила
- Пользователь может ввести **любую строку** (пустую, с пробелами, спецсимволами)
- Допускаются дубликаты (если не введено дополнительное требование)
- Регистр сохраняется как есть

### 1.4. Пример
Введите тип блюда:
Напиток
Введите название блюда:
Сок яблочный
Блюдо 'Сок яблочный' (тип: Напиток) успешно добавлено

text

## 2. Генерация комбинаций блюд

### 2.1. Описание
Приложение генерирует случайные комбинации блюд на основе:
- количества комбинаций (задаёт пользователь)
- списка типов блюд (задаёт пользователь)

### 2.2. Порядок работы

| Шаг | Действие пользователя | Реакция программы |
|-----|----------------------|-------------------|
| 1 | Выбор пункта меню `2` | `"Введите количество комбинаций:"` |
| 2 | Ввод числа N | Сохраняет число |
| 3 | `"Введите типы блюд для комбинации (каждый тип с новой строки, для завершения нажмите Enter):"` |
| 4 | Ввод типов (по одному на строку) | Добавляет тип в список |
| 5 | Пустая строка (Enter) | Завершает ввод типов |
| 6 | Проверка типов | Если тип не существует → предупреждение + предложение ввести другой тип |
| 7 | Генерация N комбинаций | Вывод результата |
| 8 | Возврат в главное меню |

### 2.3. Условия генерации

| Условие | Описание |
|---------|----------|
| **Источник** | Только ранее добавленные блюда (через пункт 1) |
| **Случайность** | Для каждого типа выбирается случайное блюдо этого типа |
| **Повторение типов** | Типы могут повторяться в одной комбинации |
| **Количество типов** | Не ограничено (от 1 и выше) |
| **Комбинации** | Каждая комбинация генерируется независимо случайным образом |

### 2.4. Валидация типов

**Если пользователь ввёл несуществующий тип:**
Тип 'Десерт' не найден. Доступные типы: Напиток, Гарнир, Мясо
Введите другой тип:

text

Пользователь **повторяет ввод** для этого же слота (тип не добавляется).

**Цикл продолжается**, пока пользователь:
- либо введёт существующий тип
- либо нажмёт Enter (завершит ввод общий)

> **Важно:** Пустая строка всегда завершает **весь** ввод типов, даже если предыдущие типы были невалидны.

Гарнир: Гречка, Картофельное пюре

### 2.8. Крайние случаи

| Ситуация | Ожидаемое поведение |
|----------|---------------------|
| Нет добавленных блюд | `"Нет добавленных блюд. Сначала добавьте блюда (пункт 1)."` → возврат в меню |
| Для запрошенного типа нет блюд | `"Нет блюд типа 'X'. Добавьте блюда этого типа через пункт 1."` |
| Пользователь ввёл 0 комбинаций | `"Количество комбинаций должно быть больше 0."` → повтор запроса |
| Пользователь ввёл не число | `"Ошибка: введите целое число."` → повтор запроса |
| Пользователь не ввел ни одного типа (сразу Enter) | `"Вы не указали ни одного типа. Генерация отменена."` → возврат в меню |

### 3.1. Описание

### 3.2. Пример
Выберите действие:
1 — Добавить новое блюдо
2 — Сгенерировать комбинации блюд
3 — Выход
3
До свидания!
